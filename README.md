## 📌 About Me
- I’m a Software Engineer focused on backend systems, distributed architecture, and infrastructure-heavy applications. I like building reliable services, designing clean APIs, and making pragmatic trade-offs around scalability, performance, and maintainability.
- Alongside backend/platform work, I have strong Web3 engineering experience across crypto trading systems, custody platforms, protocol tooling, smart contracts, cross-chain integrations, and decentralized infrastructure. My background includes work with EVM, Polkadot, Solana, Cosmos, IPFS, P2P systems, and secure execution flows, which gave me a strong engineering perspective on trust, resilience, and adversarial production environments.  ￼
- I’m especially interested in system design, async and event-driven systems, observability, networking, Linux, and developer tooling, and I use this GitHub to showcase projects that reflect practical engineering, solid architecture, and thoughtful trade-offs.
